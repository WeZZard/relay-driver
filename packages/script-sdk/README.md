# @wezzard/relay-driver-script-sdk

Relay Driver script-side SDK: wrap individual tool calls from uploaded JavaScript, TypeScript, or Python scripts with recorded-call semantics.

Part of the [Relay Driver](https://github.com/WeZZard/relay-driver) monorepo — see the [root README](https://github.com/WeZZard/relay-driver#readme) for the full project and install instructions.
